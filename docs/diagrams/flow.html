[그림 2] 비상봉투 전체 흐름

등록부터 사후 통지까지 6단계. 단계마다 존재 이유가 분명한 보안 장치를 하나씩 둔다.

① 등록·동의평시
하는 일주민센터 대면 등록, 공개 항목·관계형/봉인형 선택, 조력자 풀 등록, 가정 기기 설치
보안 장치평문엔 랜덤 ID·500m 격자만. 시민 조력자는 가구 정보 없이 등록
② 봉인·열쇠 분산평시
하는 일봉투 1·2를 AES-256-GCM으로 봉인, 데이터 키를 Shamir 2-of-3으로 기관 3곳에 분산
보안 장치구청장도 혼자 못 연다. DB 탈취 시 드러나는 것은 "칸 어딘가에 가구가 있다"뿐
③ 준비예보
하는 일서명된 예보 검증, 정책 엔진만 봉투 1을 열어 위험도 계산·가배정, 조력자에 "○○동 일대 대기"
보안 장치봉투 2(상세 정보)는 열리지 않음. 대기 호출에 주소 없음
④ 공개실제 상황
하는 일경보 또는 예보+고위험 → 지정 → 확장 A → 확장 B 순 1인 배정, 도착 확인 후 봉투 2의 허용 항목 공개
보안 장치보관 기관 3곳 독립 검증, 신뢰 등급별 최소 공개, 기기 바인딩 단기 토큰
⑤ 재봉인종료
하는 일경보 해제·유효 시간 만료 시 자동으로 다시 잠금, 토큰 폐기, 조력자 화면 정보 삭제
보안 장치공개는 위험이 확인된 시간 동안만 유지
⑥ 사후 통지종료 후
하는 일누가·언제·어떤 근거로 열었는지 당사자에게 통지, 열람 이상 탐지
보안 장치해시 체인 로그 + 보관 기관 앵커로 로그 조작 탐지
가정 센서·긴급버튼 — 기기 키로 서명된 신호는 예보 단계와 관계없이 그 가구만 즉시 공개 단계로
단계 무관 즉시 → ④ 공개
