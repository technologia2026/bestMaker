[그림 1] 비상봉투 상세 기능구성도

8개 기능군 · 28개 세부 기능. 위 줄은 평시·준비 단계에서 명단 없이 대비하는 기능, 아래 줄은 재난 시 이웃이 함께 구조하는 기능이다.

비상봉투평소엔 봉인, 재난 땐 가장 가까운 이웃이 여는 재난약자 구조 플랫폼
재난약자(당사자)지정 조력자확장 조력자 A·B담당 공무원열쇠 보관 기관 3곳가정 기기
평시·준비 — 명단 없이 대비한다

F1 등록·동의 주민센터·웹

  • F1-1재난약자 등록대면·강한 본인인증, 가구 랜덤 ID·500m 격자 부여
  • F1-2공개 항목·유형 선택공개 항목 본인 선택, 관계형/봉인형
  • F1-3조력자 등록확장 A 동행파트너 자격 연동, 확장 B 인증·교육·서약
  • F1-4가정 기기 등록기기 공개키·도착 코드 비밀 등록
사용자: 당사자, 담당 공무원, 조력자

F2 봉인·열쇠 분산 봉인 서비스

  • F2-13층 봉투 구성평문(ID·격자) / 봉투 1(건물·필요 유형) / 봉투 2(호수·상태·탈출 경로·연락처)
  • F2-2봉투 암호화봉투별 데이터 키, AES-256-GCM, AAD = 가구 ID·층·버전
  • F2-3열쇠 분산Shamir 2-of-3, 기관 3곳에 조각 보관
사용자: 시스템, 열쇠 보관 기관

F3 개봉 증거 검증 정책 엔진·보관 기관

  • F3-1공식 경보 검증Ed25519 서명·발령 시각·유효 시간·nonce
  • F3-2가정 기기 신호 검증기기 키 서명, 단조 증가 카운터
  • F3-3보조 증거 교차 확인긴급재난문자 (단독 개봉 불가)
  • F3-4보관 기관 독립 검증증거·격자·조력자 자격 확인 후 조각 제공, 관리자 요청 거부
사용자: 시스템, 열쇠 보관 기관

F4 위험도 분석 공공데이터만

  • F4-1평시 건물 취약도침수흔적·지하층·저지대·빗물펌프장 거리
  • F4-2실시간 위험도10분·1시간 강우, 하수관로·하천 수위 상승
  • F4-3기여도 기록·앞당기기항목별 근거 기록, 예보 + 고위험 시 서명된 앞당기기 선언
사용자: 시스템 (개인정보 미사용)
재난 시 — 이웃이 함께 구한다

F5 단계 판정 정책 엔진

  • F5-1단계 판정평시 → 준비(예보) → 공개(경보·고위험) → 종료
  • F5-2즉시 공개센서·긴급버튼은 단계 무관, 그 가구만
  • F5-3보수 모드준비 중 데이터 두절 시 예보 격자 공개
  • F5-4대기 호출준비 단계, 주소 없이 "○○동 일대 대기"
사용자: 시스템 → 조력자

F6 조력자 매칭 매칭 엔진

  • F6-1순차 확장 배정지정 → 확장 A → 확장 B, 위험도·거리·역량 기준
  • F6-2잠금 배정먼저 수락한 1명, 조력자당 동시 1건
  • F6-3자동 재배정무응답(3분)·거절·포기 시 다음 조력자
사용자: 지정·확장 조력자

F7 도착 확인·최소 전달 전달 서비스

  • F7-1공개 매트릭스신뢰 등급 × 단계 × 도착 여부 × 당사자 동의
  • F7-2도착 확인위치 격자 + 가정 기기 1분 일회용 코드, 5회 실패 잠금
  • F7-3단기 토큰 전달경보 유효 시간 내, 기기 바인딩, 캐시 금지, 워터마크
사용자: 배정된 조력자 1인

F8 재봉인·감사·통지 감사 서비스

  • F8-1자동 재봉인종료 시 토큰 폐기, 조력자 화면 삭제
  • F8-2해시 체인 감사 로그체인 끝 해시를 보관 기관 3곳에 앵커 기록
  • F8-3당사자 열람 통지"22:14, 확장 조력자 1명 열람, 근거: 공식 침수경보"
  • F8-4열람 이상 탐지수락·포기 반복, 격자 밖 시도, 심야 관리자 조회 → 계정 정지
사용자: 당사자, 감사 기관
